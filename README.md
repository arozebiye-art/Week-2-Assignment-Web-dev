Expense Tracker
Project Description

The Expense Tracker is a simple web page built using HTML5 and CSS3. It demonstrates how to organize and display personal expenses and provides a form for entering expense information.

Features
Expense table with Name, Amount, Category, and Date columns.
Five sample expense records.
Add Expense form with name, amount, category, and date fields.
Category dropdown with Food, Transport, Rent, Entertainment, and Other.
Logo image and embedded YouTube video.
Collapsible instructions using HTML details and summary elements.
Styled table with borders, alternating row colors, and hover effects.
Responsive styling for the embedded video.
Advanced CSS selectors, including descendant, child, positional, negation, and focus selectors.
Project Files
index.html — Contains the page structure, form, expense table, image, video, and instructions.
style.css — Controls the page layout, colors, typography, form appearance, and table styling.
README.md — Describes the project, its features, and its files.
Technologies Used
HTML5
CSS3
How to Run
Download or clone this repository.
Open index.html in a web browser.
Explore the expense table, form, and interactive elements.
